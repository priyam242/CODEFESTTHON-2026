--------------------------------------------------------------------------------
0. PROJECT SPECIFICATION BASELINE
--------------------------------------------------------------------------------
- Project Name & Idea:
  * RentShield: An AI-arbitrated and cryptographically sealed rental inventory 
    protocol that prevents unfair security deposit deductions. It computes 
    in-browser SHA-256 hashes of room items at move-in for landlord lock-in, and 
    uses Google Gemini 2.5 Flash multimodal AI at move-out to objectively distinguish 
    normal wear-and-tear from genuine tenant damage with transparent rupee cut breakdowns.
- Selected Track:
  * AI-ML (Primary): Multimodal inspection, reasoning, and damage deduction scoring.
  * Open Innovation / FinTech (Secondary): Deposit protection escrow, verifiable certificates.
- Tech Stack:
  * Client: React 19, TypeScript, Vite 6, Tailwind CSS v4, Lucide Icons, jsPDF.
  * Server: NestJS 11, Express 5, Prisma ORM 6, PostgreSQL (with in-memory fallback), Passport JWT.
  * AI Engine: Google GenAI SDK (`@google/genai`), Gemini 2.5 Flash model.
  * Cryptography: Web Crypto API (`window.crypto.subtle.digest`) for zero-server upload verification.
  * Realtime: HTML5 `BroadcastChannel` API (`rentshield_live_sync`) with cross-tab event bus.
- Re-used Code & Third-Party Disclosures:
  * Official CLI boilerplate (NestJS CLI & Vite React TS template).
  * Standard open-source packages (@google/genai, jspdf, lucide-react, tailwindcss, prisma).
  * 100% of domain business logic, cryptographic hash chains, and arbitration prompts built during hackathon.
