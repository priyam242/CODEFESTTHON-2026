1. ROOT CAUSE OF SILENT AUDIT ACCEPTANCE & RUBBER-STAMPING
================================================================================
During live user testing, uploading a dark website screenshot against a bright beige
living room sofa move-in baseline was blindly accepted with the hardcoded string:
"Under Model Tenancy Act (MTA) 2021 Sec 13, sofa and wall exhibits standard fair wear-and-tear..."

Forensic Root Causes Identified:
1. SDK Silent Fallback: The previous implementation relied on the `@google/genai`
   SDK wrapper which failed silently due to model name mismatches (e.g. invalid
   'gemini-3.5-flash' alias or missing environment keys), automatically routing all
   requests to the local fallback function.
2. Keyword-Biased Rubber-Stamp: The fallback function contained a regex check:
   `const isCleanKeyword = /clean|intact|good condition|no damage|normal|fine/i.test(outLower);`
   Because default move-out notes were pre-filled with "Clean condition, normal usage, dust cleaned",
   `isCleanKeyword` evaluated to `true`, completely bypassing visual evaluation and
   returning `aiVerdict: 'NORMAL_WEAR_TEAR'` and `suggestedCut: 0`.
